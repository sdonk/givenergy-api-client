# Implementation Plan: SDK Documentation

**Branch**: `002-sdk-docs` | **Date**: 2026-03-08 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/002-sdk-docs/spec.md`

## Summary

Produce comprehensive developer documentation for the GivEnergy API Client SDK, published
via MkDocs with the Material theme to GitHub Pages. The docs cover all five resource types
(Account, Inverter, EMS, EV Charger, Inverter Presets) with sync/async tab examples, a
complete error-handling reference, and advanced topic guides (pagination, open-schema
responses, datetime requirements). All code snippets are validated as runnable on every CI
run using pytest's doctest mode against a mocked client.

## Technical Context

**Language/Version**: Python 3.12+ (SDK) + Markdown (docs content)
**Primary Dependencies**: `mkdocs-material>=9.6` (MkDocs + Material theme in one package)
**Storage**: Markdown files in `docs/`; static HTML output in `site/` (gitignored)
**Testing**: `pytest --doctest-glob="docs/*.md"` with `pytest-httpx` mocked client
**Target Platform**: GitHub Pages (static site; `site_url` already set in `mkdocs.yml`)
**Project Type**: Documentation site
**Performance Goals**: `mkdocs build` completes in <30s; pages load in <1s on standard connections
**Constraints**: No new runtime dependencies; docs build must not require live API credentials
**Scale/Scope**: 9 Markdown pages; ~5 code snippets per resource page; one `mkdocs.yml` nav
